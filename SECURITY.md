# セキュリティポリシー / Security policy

脆弱性を見つけた場合は、公開の Issue や PR には書かず、GitHub の **Private vulnerability reporting** で非公開に報告してください。

1. このリポジトリの **Security** タブを開く
2. **Report a vulnerability** から内容を送る

再現手順、影響する URL や環境、想定される影響を書いてもらえると助かります。確認でき次第、返信して対応します。対象は `main` ブランチと本番サイト <https://anone.yoiailabs.com> です。

---

Please do **not** report security vulnerabilities in public issues or pull requests. Use GitHub's **Private vulnerability reporting** instead: open the **Security** tab of this repository and choose **Report a vulnerability**. Include steps to reproduce, affected URLs or environments, and the expected impact. Supported targets are the `main` branch and the production site <https://anone.yoiailabs.com>.
