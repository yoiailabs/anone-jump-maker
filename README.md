# あのねジャンプメーカー

写真を置くと、縦テンプレのジャンプに合わせて入れ替わる小さなメーカーです。ファン制作です。本番予定 URL は [https://anone.yoiailabs.com](https://anone.yoiailabs.com) です。写真はサーバーに出さず、この端末の中だけで重ねます。

画面はナナツカゼさんのテンプレの空気に寄せています。太い線、ベタ塗りの色面、少し昔の電子ポップのような夏の残像。よいらぼの紺や金は使いません。フォントは Klee One と Zen Maru Gothic（Google Fonts）です。

## 使い方

1. 写真を数枚選ぶ
2. 「書き出す向き」で縦（9:16）か横（16:9）を選ぶ
3. テンプレのベタ塗り背景（緑クロマに限らない）をキーイングして、線画キャラを残す
4. 検出したジャンプ・カットで写真を差し替える。枚数が足りなければ循環
5. プレビューして MP4 または WebM を保存（オフライン生成）。テンプレをリアルタイム録画せず、30fps の論理時刻でシークして同じ compositor を描き、WebCodecs + mediabunny で映像とテンプレ音声を mux します。WebCodecs が使えないブラウザでは録画に落とさず、Chrome / Edge を案内します。

**縦**はテンプレと同じ 608×1080 です。中央にシャープな 16:9 本編（差し込み写真＋緑クロマを抜いた線画キャラ）を置き、上下帯はその本編フレーム全体を cover した強いブラー＋暗転です（写真だけのブラーではありません）。本編の位置はテンプレ緑帯の実測（y=312–654）に合わせます。本編内の写真はカット拍で縦 hop します。

**横**は 1280×720（プレビューと保存で同じ）。上下ブラー帯はなく、キャンバス全体が 16:9 本編です。差し込み写真が背景、線画キャラは前面（白ステッカー縁、1.35 倍・下揃え。縦の 1.7 を横全面に当てると例より寄りすぎるため）。切替は **ジャンプ**（現行 hop）か、参考投稿（hagikaze_sami）の **ズーム**（カット間は静止。切替は 2–5 フレの放射ズームブラーで、出ていく写真が中心へ縮み、入ってくる写真は寄った状態から引く＝ズームアウト。横ストリークと RGB ずれ、軽い波打ち。切替の 1 フレ前から短い白いハイライト。ジャンプのほぼ全白ではなく、wipe / 回転は使わない）を選べます。公式テンプレは `public/template/landscape.mp4`（1920×1080）です。

写真のスロット切替はパッと差し替えません。参考横動画（30fps）ではカットの 1 フレ前から白フラッシュが立ち上がり、切替フレームはほぼ白飛び、新写真はパンチズーム＋短い横ズレ／色分れのあと hop に入ります。同じエンベロープを縦の本編写真にも載せます（上下ブラー帯の構図は変えない）。

公式の「ナナツカゼ」「あのね」等の文字はユーザー差し込み側に足しません。

写真の向きは EXIF を `createImageBitmap({ imageOrientation: "from-image" })` で直し、WebGL には ImageBitmap を直接上げません（`UNPACK_FLIP_Y_WEBGL` との二重反転を避けるため、Canvas2D に描いてからテクスチャ化します）。読み込み時に長辺 1920 程度へ縮小し、元の巨大画素と File の ObjectURL は持ちません。サムネは別の小さいコピー、decode は最大 2 枚ずつです。写真は端末内のみです。

## 開発

```bash
pnpm install   # または npm install
pnpm dev       # または npm run dev
pnpm test
pnpm build
```

デプロイ（DNS は設定しない）:

```bash
pnpm deploy    # = pnpm build && wrangler deploy
```

Worker 名は `anone`。Cloudflare Workers の静的アセットとして `dist` を配信します。`/api/*` だけ Worker が先に処理します。

プレビューを開始したときと、保存が成功したあとに、写真や動画は送らず「1回作った」イベントだけをサーバーに残します。同じ人が何度作っても毎回数えます（IP・Cookie・端末による重複排除はしません）。プレビューを途中で止めても、開始時にすでに数えているので減らしません。同じプレビュー再生で開始を二度数えることはありません（停止してから再開すればまた +1）。公開 UI は合計件数（「○回作られたよ」）だけ出します。永続化は Durable Object（バインディング `GENERATE_STATS` / クラス `GenerateStats`、SQLite）です。単なる整数カウンタにせず、サーバー付与の UTC 時刻と、ブラウザ／OS／画面の粗い属性だけを行として残します。属性の `action` は `preview` または `save` です。保存の `exportMode` は生成固定（`offline`）です。API が落ちても保存自体は成功のままです。

- `GET /api/stats` → `{ count }`
- `POST /api/stats/generate` → イベントを足して `{ count }`

カット表は向き別です。

- 縦 `public/template/cuts.json` … 緑 16:9 帯を 15fps で抜き、画素差（pix>8、最短間隔 0.22 秒）。32 スロット
- 横 `public/template/landscape-cuts.json` … 横テンプレ全面を同じ条件で検出。30 スロット

## キーイング

背景は純緑クロマではなく、ティール・ライム・グレー・赤・紫などフレームごとに変わるベタ塗りです。四隅と上辺から優勢な背景色を毎フレーム推定し、色距離で抜きます。緑が勝つ画素は補助的に抜き、暗い線画は不透明のまま残し、キー色の巻き込み（スピル）を抑えます。WebGL フラグメントシェーダが本線で、未対応時は Canvas2D に落とします。
