# 使い方

本番は [https://anone.yoiailabs.com](https://anone.yoiailabs.com) です。ここにある手順は、そのサイトでも手元の開発サーバーでも同じです。

## 動画を作る

1. 写真を数枚選ぶ。並びは選んだ順のままです。ファイル名や更新日時では並べ替えません。
2. 向き、エフェクト、フィルター、線画の大きさを選ぶ。向きは縦（9:16）か横（16:9）、エフェクトはジャンプかズーム、フィルターはなし／ブラー（弱）／ブラー（強）、線画は標準／1.2／1.4 です。初期値は横・ズームです。
3. テンプレのベタ塗り背景を抜いて、線画のキャラを残します。緑一色のクロマとは限りません。
4. 拍（テンプレのポーズが切り替わるタイミング）で写真が差し替わります。枚数が拍より少ないときは、同じ順で先頭から繰り返します。
5. プレビューして、MP4 または WebM を保存します。生成はオフラインで、この端末の中だけで終わります。

プレビューは最初、音声がオンです。モーダルの「音声オン／音声オフ」で切り替えられます。これは画面の `video` のミュートだけで、保存した動画の音声には影響しません。保存動画の音声はテンプレファイルから mux します。

保存サイズは縦 1080×1920、横 1920×1080 です。差し込み写真はキャンバス全面に cover します。線画は前面です。縦の線画も、画素の出どころは横テンプレと同じ `public/official-assets/template/landscape.mp4` です。

フィルターは差し込み写真だけにかかり、線画にはかかりません。プレビューのダイアログでも、向きとエフェクトと同じように切り替えられます。

公式の「ナナツカゼ」「あのね」といった文字は、ユーザーの写真側には足しません。

## 共有

できた動画への推奨は、`#あのねジャンプ` と `#あのねジャンプメーカー` を付けて X に投稿することです。動画ファイルの添付は手元でします。

操作パネルの枠の外にある「共有する」は、最初から押せます。Web Share API（`navigator.share({ text })`）で、本文 `#あのねジャンプ #あのねジャンプメーカー` だけを渡します。`url` と `title` は付けません。共有シートが無い環境では、同じ本文をクリップボードへコピーします。

その下の「ハッシュタグをコピー」も最初から押せます。ボタンの下に、コピーされる本文を小さく出しています。本文の定義は `src/share.ts` の `SHARE_TEXT` です。どちらのボタンも、このサイトの URL は足しません。

## 読める写真

JPEG、PNG、WebP を読めます。向きは EXIF を `createImageBitmap({ imageOrientation: "from-image" })` で直します。それが落ちる端末では、options なしの `createImageBitmap`、HTML の Image、FileReader の data URL の順に試します。MIME が空でも、拡張子かマジックバイトが JPEG / PNG / WebP なら残します。

Android のカメラ写真（HEIC / HEIF）は、そのブラウザがネイティブで読めないときだけ `heic-to`（libheif）を読み、JPEG 相当に変換してから同じ経路に渡します。変換できない環境では、互換性優先（JPEG）かスクリーンショットを案内します。JPEG / PNG / WebP の読み込みには、このデコーダを載せません。

読み込み時に長辺 2880 まで縮小し、元の巨大な画素と File の Object URL は持ちません。サムネイルは別の小さいコピーです。同時にデコードするのは最大 2 枚です。

## 画面のほかの導線

画面の下には、ナナツカゼさんの X、Instagram、YouTube、TikTok、Spotify、Apple Music へのリンクを並べています（`src/links.ts`。公式サイト https://www.nanatsukaze.com/ と同じ並び）。どれも別タブで開き、`rel="noopener noreferrer"` を付けます。公式ロゴの画像は置かず、テンプレに寄せたアイコンを自作しています。

「反応」には、X の投稿を公式の埋め込みで置きます（`src/reactions.ts`）。埋め込みのスクリプトが来るまでは、本文と元投稿へのリンクが見えます。「みんなの #あのねジャンプ」は `src/community-jumps.ts` の一覧です。掲載をやめてほしいときの連絡は [NOTICE.md](../NOTICE.md) です。
