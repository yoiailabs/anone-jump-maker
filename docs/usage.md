# 写真から動画を作る

[制作画面](https://anone.yoiailabs.com/make)で写真を選び、プレビューを見ながら動画を作れます。写真の並べ方、見た目の調整、保存の手順は次のとおりです。

## 写真を選んで並べる

「写真を追加」から1〜32枚を選びます。選択した並び順で表示され、あとから追加した写真は末尾に入ります。写真の「×」で削除し、PC ではドラッグ、スマートフォンでは長押しして並べ替えます。

写真の下の数字は、その写真が映るカット番号です。32カットを写真の並び順で埋め、枚数が少ない場合は先頭から繰り返します。写真は画面いっぱいに表示するため、縦横比によって端が切れます。

JPEG・PNG・WebP など、ブラウザが読み込める画像を使います。HEIC / HEIF は標準の読み込みが使えない場合に端末内で変換を試します。読み込みに失敗するときは、JPEG や PNG に変換した画像を選んでください。

## 見た目と音を確認する

写真を入れるとプレビューの再生ボタンが使えます。再生位置はシークバーで変えられます。

| タブ | 選べる設定 |
| --- | --- |
| 向き | 横 16:9 / 縦 9:16 |
| エフェクト | ズーム / ジャンプ |
| フィルター | なし / ブラー（弱）/ ブラー（強） |
| サイズ | キャラクターの大きさ：標準 / 1.2 / 1.4 |

最初は横・ズーム・フィルターなし・標準サイズです。フィルターは写真にかかり、キャラクターの線画にはかかりません。

プレビューの音声は最初からオンです。スピーカーボタンで消音しても、保存する動画にはテンプレ映像の音声が入ります。

## 動画を生成して保存する

1. 「動画を保存」を押します。生成中は進捗が表示され、「キャンセル」で中断できます。
2. 完了後に「ダウンロード」を押します。動画は MP4 を優先し、対応状況に応じて WebM になります。
3. 共有シートが開いた場合は、保存先や送信先を選びます。ファイル共有に対応しない環境では通常のダウンロードになります。

出力サイズは横 1920×1080、縦 1080×1920 です。生成には数十秒かかることがあります。

共有シートには動画ファイルを渡します。対応していれば `#あのねジャンプ #あのねジャンプメーカー` も添えます。X に投稿する場合は、保存した動画とこのハッシュタグを使えます。

> [!TIP]
> 「動画の生成に未対応」と表示された場合は Chrome または Edge で開いてください。プレビューが動いていても、動画生成に必要な機能が使えない環境があります。

写真は端末内で処理します。外部通信については[アーキテクチャ](architecture.md)、投稿や素材の権利については [README](../README.md#ライセンス)を参照してください。
